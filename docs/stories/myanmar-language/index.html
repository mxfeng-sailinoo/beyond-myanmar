Myanmar Language｜從一句問候開始

一句「မင်္ဂလာပါ」，是向陌生世界打開的一扇門。

THE STORY / 故事

初次見面時，一句緬甸語問候往往就能讓對話更親近。字母圓潤、聲調富有節奏，但語言並不只是一套字形：每句話都會受到情境、禮貌與說話對象的影響。

✦
CULTURAL CONTEXT / 文化背景

藏在日常裡的意義

緬甸語（Burmese / Myanmar language）是緬甸廣泛使用的語言之一，使用緬甸文字書寫。緬甸境內另有多種民族語言；本頁介紹的問候詞不代表所有語言或地方口音。

THREE THINGS TO NOTICE

從三個細節認識文化

01

မင်္ဂလာပါ — 常見正式或禮貌的問候。

02

ကျေးဇူးတင်ပါတယ် — 表達感謝。

03

နေလို့ကောင်းလား / နေကောင်းလား — 視語境問候對方近況。
