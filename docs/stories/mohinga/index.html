Mohinga｜一碗緬甸的早晨

一碗魚湯米線，盛著香氣、早餐的忙碌，以及不同家庭記憶中的味道。

THE STORY / 故事

清晨的攤位漸漸熱鬧，熱湯澆上細米線，再撒上各式配料。有人喜歡炸豆餅的酥脆，有人喜歡湯底的濃郁。Mohinga 是許多人熟悉的味道，也是地方食譜各有變化的料理。

✦
CULTURAL CONTEXT / 文化背景

藏在日常裡的意義

Mohinga（မုန့်ဟင်းခါး）通常以米線搭配魚湯或香料湯底，常見配料有炸物、香草或其他地方習慣的食材。它經常與早餐聯想在一起，但不只限於早晨享用；各地做法不同。
