01 / 日常的美

Thanaka｜一抹香木粉的日常

在許多緬甸人的臉頰上，文化不是陳列品，而是一道每天都能看見的淡金色印記。

THE STORY / 故事

早晨的木盤上，幾滴水與一小段香木被慢慢磨成細緻的糊狀。有人塗成圓形，有人畫成葉片。Thanaka 不只是一種臉部用品，也是許多人熟悉的家庭日常。

✦
CULTURAL CONTEXT / 文化背景

藏在日常裡的意義

Thanaka（緬文：သနပ်ခါး）通常由特定樹木的木材或樹皮加水研磨成糊，用於臉部與皮膚。它與日常保養、審美習慣及文化認同相連；使用方式因家庭、地區及個人而異。
