03 / 節慶與習俗

Thingyan｜一場水花迎新年

節日裡的水不只是熱鬧，也象徵告別舊的一年，迎接新的開始。

THE STORY / 故事

四月的城市與城鎮，音樂、歡笑與潑水帶來新年的氣氛。但 Thingyan 並不只有水花：有人回家探親，有人向長輩致敬，也有人布施、禪修，或參與社區活動。

CULTURAL CONTEXT / 文化背景

藏在日常裡的意義

Atā Thingyan 是緬甸傳統新年節慶，通常在四月中旬舉行。潑水象徵洗去舊年的不順與迎接更新。各社群慶祝方式有所不同。UNESCO 於 2024 年將它列入人類非物質文化遺產代表作名錄。
